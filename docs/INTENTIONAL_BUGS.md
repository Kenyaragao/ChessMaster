# Erros Intencionais (exercício de teste "caixa preta")

> Como parte do trabalho prático de teste de software pelo método da caixa
> preta, esta versão do ChessMaster deve conter de 5 a 8 erros inseridos
> intencionalmente, de naturezas diferentes (lógicos, de interface,
> sintáticos, etc.), para que sejam encontrados por uma equipe de teste
> externa **sem conhecimento prévio desta lista**.

Este documento está reservado para a etapa final do desenvolvimento, na
qual os erros serão inseridos em commits próprios e devidamente descritos
aqui: identificador, localização no código, tipo do erro e método de
detecção recomendado (por exemplo, em quais condições de execução o erro se
manifesta).

**Status:** pendente — será preenchido antes da entrega do relatório final,
depois de concluídas todas as funcionalidades planejadas para a versão
"correta" do jogo.
